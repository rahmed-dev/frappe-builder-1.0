# Create Roadmap Workflow

Purpose: Build a phased implementation roadmap from TSD/features with milestones and dependencies.

Inputs: Technical Specification (or feature list) and dependency notes.

Outputs: Phased roadmap with tasks, milestones, and dependency mapping.

Entrypoint: `{project-root}/.bmad/frappe-builder/workflows/create-roadmap/workflow.yaml`

Usage: Invoke via agent command `*plan` (Frappe-Planner) or direct workflow path.
