# Review Code Workflow

Purpose: Scan code for Frappe anti-patterns and recommend framework-native fixes.

Inputs: Code paths or recent changes; project/app/site context.

Entrypoint: `{project-root}/.bmad/frappe-builder/workflows/review-code/workflow.yaml`

Usage: Invoke via agent command `*review` (Frappe-Dev/Frappe-Debugger) or direct workflow path.
