# Design Solution Workflow

Purpose: Produce a Technical Specification Document (TSD) using the 4-tier framework (Standard → Configure → Scripts → Custom) from the BRD.

Inputs: Business Requirements Document; project/app/site context.

Outputs: TSD with DocType/UX/workflow design, tier decisions, and implementation guidance.

Entrypoint: `{project-root}/.bmad/frappe-builder/workflows/design-solution/workflow.yaml`

Usage: Invoke via agent command `*design` (Frappe-Architect) or direct workflow path.
