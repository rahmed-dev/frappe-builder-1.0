## [1.0.0] - 2025-11-24

### Added
- **8 Specialized Agents** for Frappe/ERPNext development
  - Frappe-Nexus: Primary orchestrator agent
  - ERPNext BA: Business Requirements Analyst
  - Frappe-Architect: Solution Architect
  - Frappe-Planner: Implementation Planner
  - Frappe-Dev: Code Developer
  - Frappe-Debugger: Error Diagnostician
  - Doc-Writer: Documentation Generator
  - QA-Specialist: Test Scenario Generator

- **10 Workflows** covering complete SDLC
  - CORE: analyze-requirements, design-solution, implement-feature
  - PLANNING: create-roadmap, sequence-tasks
  - QUALITY: diagnose-issue, generate-tests, review-code
  - DELIVERY: create-guide, prepare-release

- **Frappe Bench Awareness**
  - Automatic detection of Frappe bench installation
  - Dynamic app selection and path configuration
  - Session-based app context management

- **4-Tier Framework** implementation guidance
  - Standard → Configure → Scripts → Custom
  - Anti-pattern detection for Frappe development

- **Module Infrastructure**
  - Complete agent sidecar system
  - Standards and templates
  - Knowledge base structure
  - Reusable tasks library
  - Interactive installer with configuration

- **Orchestrated Workflows**
  - full-cycle: Complete development lifecycle
  - quick-build: Fast implementation from existing design
  - troubleshoot: Error diagnosis and fixing

### Documentation
- Comprehensive README with quick start guide
- Agent documentation with command reference
- Workflow descriptions and usage examples
- Installation and configuration instructions
